A short original poem about agency — the power to stop and to stay — written for the [make.fun bounty "The poem about stopping"](https://make.fun/bounty/the-poem-about-stopping-20261121-1927). The program `main.py` writes the poem, deterministically and with no network, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3.13 (stdlib only). The output is one UTF-8 poem of 1–280 characters; the program checks that bound itself before writing.
